# seo-release-check

1. Confirme canonical, robots.txt, sitemap, hreflang quando aplicável e status HTTP.
2. Revise headings, metadados únicos, alt text, schema JSON-LD e links internos.
3. Verifique rendering, mobile, Core Web Vitals e páginas 404/redirects com ferramentas reais.
4. Não invente pontuação Lighthouse; anote ferramenta e resultado.
5. Entregue checklist acionável com priorização e evidências por URL.
