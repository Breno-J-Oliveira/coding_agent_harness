# Checklist de release

- [ ] Escopo e PR revisados; nenhum arquivo estranho no diff.
- [ ] Build, lint, tipos e testes automatizados executados.
- [ ] E2E para caminhos críticos com evidências.
- [ ] Mudanças de autenticação/autorização aprovadas.
- [ ] Segredos e dependências revisados.
- [ ] Migrações planejadas, backup e rollback verificados.
- [ ] Responsividade, teclado, formulários e estados essenciais revisados.
- [ ] SEO/indexação verificados apenas nas páginas públicas afetadas.
- [ ] Métricas e alertas disponíveis no deploy.
- [ ] Ambiente de preview revisado.
- [ ] Aprovação humana para deploy em produção.
- [ ] Release ID, horário e responsável registrados.
- [ ] Plano de monitoramento e rollback estabelecido.
